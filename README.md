# VTechPhone
#1. VTechPhone là hệ thống website bán điện thoại được xây dựng theo mô hình web Java. Source code tổ chức thành các lớp Entity, DAO, Service, Servlet và các trang JSP. Người dùng có thể đăng ký, đăng nhập, xác thực email, tìm kiếm sản phẩm, xem chi tiết, thêm sản phẩm vào giỏ hàng, đặt hàng và quản lý hồ sơ. Nhóm quản trị có các chức năng quản lý sản phẩm, thương hiệu, danh mục, người dùng, đơn hàng và doanh thu.
